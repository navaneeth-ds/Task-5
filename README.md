# Task-5
# 🚢 Titanic Dataset – Exploratory Data Analysis

## 📌 Task Overview

This project is part of the **Data Analyst Internship – Task 5**.

The objective of this task is to perform **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python and identify important patterns and relationships in the data.

## 🎯 Objectives

- Understand the structure of the Titanic dataset.
- Identify missing values.
- Perform basic data exploration.
- Analyze passenger survival patterns.
- Study relationships between numerical variables.
- Visualize important patterns using charts.
- Summarize the key findings from the analysis.

## 🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Seaborn
- 📓 Jupyter Notebook
- 💻 Visual Studio Code

## 📂 Dataset

The **Titanic dataset** was used for this analysis.

The dataset contains information about passengers, including:

- Passenger survival
- Passenger class
- Gender
- Age
- Number of siblings/spouses
- Number of parents/children
- Fare
- Port of embarkation

## 🔍 Analysis Performed

The following EDA steps were performed:

1. Loaded the Titanic dataset.
2. Examined the dataset structure and dimensions.
3. Checked data types.
4. Identified missing values.
5. Generated descriptive statistics.
6. Analyzed survival distribution.
7. Analyzed survival based on gender.
8. Analyzed survival based on passenger class.
9. Created an age boxplot to identify the distribution and possible outliers.
10. Created a correlation heatmap to examine relationships among numerical variables.
11. Created a pairplot to explore relationships among numerical variables.

## 📊 Visualizations

The analysis includes:

- 📊 Survival Distribution
- 👩‍🦰 Survival by Gender
- 🎫 Survival by Passenger Class
- 📦 Age Boxplot
- 🔥 Correlation Heatmap
- 📈 Pairplot

## 💡 Summary of Findings

The Exploratory Data Analysis of the Titanic dataset revealed several important patterns.

- Survival was not evenly distributed among passengers.
- Gender showed noticeable differences in survival outcomes.
- Female passengers generally had better survival outcomes than male passengers.
- Passenger class showed differences in survival outcomes.
- First-class passengers generally had better survival outcomes than passengers in lower classes.
- The correlation analysis showed relationships among the numerical variables, including passenger class and fare.
- The age boxplot helped identify the distribution of passenger ages and possible outliers.
